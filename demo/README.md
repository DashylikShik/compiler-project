# Demo-программы

Эта папка содержит демонстрационные программы для финального показа.

## Запуск

```bash
bash demo/run_demo.sh
```

или:

```bash
make demo
```

## Основные demo

- `arrays_demo.src` — массивы и доступ по индексу;
- `external_demo.src` — `printf`, `malloc`, `free`, `strlen`;
- `free_demo.src` — минимальный пример `malloc/free`;
- `optimization_demo.src` — constant folding и dead code elimination;
- `factorial.src` — рекурсия;
- `quicksort.src` — алгоритмический пример с массивами, если текущий backend его поддерживает.
