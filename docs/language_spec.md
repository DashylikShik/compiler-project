# Спецификация языка MiniCompiler

Документ описывает поддерживаемый язык проекта MiniCompiler на момент финального спринта.

## 1. Общая характеристика

Язык является C-подобным учебным языком. Программа состоит из объявлений функций, структур, внешних функций и операторов верхнего уровня, которые парсер преобразует в AST.

Главная функция:

```c
fn main() -> int {
    return 0;
}
```

## 2. Лексика

Поддерживаются:

- идентификаторы: `x`, `counter`, `_temp`, `value123`;
- целые числа: `0`, `42`, `2147483647`;
- числа с точкой: `3.14`, `0.5`, `10.0`;
- строки: `"hello"`;
- булевы значения: `true`, `false`;
- однострочные и многострочные комментарии.

Ключевые слова:

```text
int float bool void struct fn extern if else while for return true false
```

Операторы:

```text
+ - * / % = += -= *= /= == != < <= > >= ! & | && || -> ...
```

Разделители:

```text
( ) { } [ ] ; , : .
```

## 3. Типы

Базовые типы:

```text
int
float
bool
string
void
```

Дополнительно используются C-подобные pointer-формы для внешних функций:

```text
char*
void*
int*
```

В семантическом анализе указатели упрощённо допускаются для взаимодействия с внешними C-функциями.

## 4. Функции

Объявление функции:

```c
fn add(int a, int b) -> int {
    return a + b;
}
```

Если возвращаемый тип не указан, функция считается `void` там, где это поддерживается парсером.

Вызов функции:

```c
int result = add(5, 3);
```

Проверяется количество аргументов и совместимость типов.

## 5. Внешние функции

Синтаксис:

```c
extern int printf(char* format, ...);
extern void* malloc(int size);
extern void free(void* ptr);
```

Вариадическая функция допускает больше аргументов, но требует обязательные параметры. Например `printf()` без форматной строки является семантической ошибкой.

## 6. Переменные

Объявление:

```c
int x;
int y = 10;
float f = 3.14;
bool ok = true;
```

Присваивание:

```c
x = x + 1;
```

## 7. Выражения

Поддерживаются:

- арифметические операции;
- сравнения;
- логические операции;
- унарные операции;
- вызовы функций;
- доступ к массиву.

Пример:

```c
int x = 5 + 3 * 2;
bool b = x > 10 && true;
```

## 8. Управляющие конструкции

### if/else

```c
if (x > 0) {
    return 1;
} else {
    return 0;
}
```

Условие должно иметь тип `bool`.

### while

```c
while (i < 10) {
    i = i + 1;
}
```

### for

```c
for (int i = 0; i < 5; i = i + 1) {
    sum = sum + i;
}
```

## 9. Массивы

Объявление:

```c
int arr[5];
```

Инициализация:

```c
int arr[3] = {1, 2, 3};
```

Доступ и присваивание:

```c
arr[2] = 10;
return arr[2];
```

Многомерные массивы:

```c
int matrix[3][4];
matrix[1][2] = 42;
```

Массивы как параметры:

```c
fn sum(int arr[], int size) -> int {
    int total = 0;
    for (int i = 0; i < size; i = i + 1) {
        total = total + arr[i];
    }
    return total;
}
```

Для константных индексов выполняется семантическая проверка границ:

```c
int arr[5];
arr[5] = 10; // ошибка
```

## 10. Структуры

Синтаксис структур присутствует в парсере и семантической таблице символов:

```c
struct Point {
    int x;
    int y;
}
```

Поддержка структур в backend зависит от текущей реализации.

## 11. Память

Локальные массивы в x86 backend выделяются через `malloc`. Внешний `free` можно вызвать явно:

```c
extern void* malloc(int size);
extern void free(void* ptr);

fn main() -> int {
    void* p = malloc(16);
    free(p);
    return 0;
}
```

## 12. Ошибки

Категории ошибок:

- лексические;
- синтаксические;
- семантические;
- ошибки генерации и сборки.

Формат семантической ошибки включает строку, колонку и указатель `^` на проблемное место.
